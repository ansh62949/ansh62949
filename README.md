<br>

> **Repository:** [ansh62949/prsense-ai](https://github.com/ansh62949/prsense-ai) &nbsp;|&nbsp; **Live Demo:** [prsense-ai.vercel.app](https://prsense-ai.vercel.app)

PRSense is a repository-aware multi-agent LLM review platform that automates pull request audits through semantic code analysis and domain-specialized AI agents.

- Architected a multi-agent review workflow using **LangGraph**, orchestrating dedicated agents for security vulnerabilities, architectural consistency, code style, and test coverage across GitHub PR diffs.
- Built a high-precision **RAG pipeline** using repository embeddings and **pgvector (HNSW, cosine similarity)** on PostgreSQL for context-aware code retrieval.
- Integrated **GitHub Webhooks** with a **FastAPI** async background worker and **Spring Boot** service layer to drive non-blocking review workflows.

<br>

> **Repository:** [ansh62949/codesphere](https://github.com/ansh62949/codesphere)

CodeSphere is a microservices-based online judge platform designed to process concurrent code submissions in isolated, secure execution environments.

- Architected **7+ independently deployable microservices** (API Gateway, Auth, Submission, Runtime, Leaderboard) in Java/Spring Boot using **Eureka** service discovery.
- Decoupled code execution load from HTTP endpoints by processing submission jobs asynchronously over **RabbitMQ**, backed by a **Redis sorted-set leaderboard** for fast rank retrieval.
- Built a secure **Linux/Docker sandbox** supporting Java, Python, and C++ code execution with memory constraints, execution timeouts, and fork-bomb protection.

> **Repository:** [ansh62949/herride](https://github.com/ansh62949/herride) &nbsp;|&nbsp; **Live Demo:** [herride-six.vercel.app](https://herride-six.vercel.app)

HerRide is an event-driven ride-hailing MVP engineered to provide secure real-time driver matching and immediate safety escalation for female passengers.

- Engineered an event-driven backend using **Apache Kafka** across 4 dedicated topics to decouple ride matching, status notifications, and emergency SOS alerts.
- Implemented real-time nearby-driver discovery using **Redis GEO** (`GEOADD`/`GEORADIUS`) and constructed a WebSockets-enabled SOS escalation pipeline connected to an admin dashboard.
- Secured API and WebSocket interfaces via **JWT (access + refresh token rotation)** with Spring Security, backed by **Prometheus & Grafana** metrics monitoring.
